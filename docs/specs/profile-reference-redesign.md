# Personal profile reference redesign

- Retain the Expo/React Native stack, shared red/white tokens and authenticated profile editing. Desktop: ~260 px left identity/menu card and flexible right account table; mobile stacks with usable menu and readable rows. Match cover/avatar overlap, rounded white panels, separators, red selected menu/edit action, referral copy pill and real status badge.
- Extend existing profile DTO with optional cover, gender, birth date, referral identity display, created/updated timestamps, status and verification flags. Update optional fields only when supplied; validate HTTPS images, gender0..2 and nonfuture birth date. No schema migration. Do not expose another account's private profile/contact data through referral lookup.
- Keep profile read mode, explicit edit/save/cancel, read-only account dates/status/referral code. Avatar/cover changes use authenticated image upload with existing image validation/rate limiting; use gallery picker, never camera/microphone. Real user photos only; scenic fallback is decorative SVG, no invented portrait.
- Menus: personal info, phone verification status/support (no SMS provider exists), password change, sessions, notifications. Existing email verification stays available. Do not invent a phone OTP or mark a phone verified locally.
- Verify backward-compatible profile updates, validation/privacy, guest state, desktop/mobile, edit/cancel/save and image/copy errors. Existing tests/build/lint plus isolated fixtures; no production profile changes or real outbound messages/uploads during testing. No commit/deploy unless requested.
- Sequence: profile DTO/service/validators + tests → independent identity/table/editor components → page/navigation/gallery upload → full regressions → browser visual verification and handoff.
